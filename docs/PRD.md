# PRD：中国市场稳健理财量化投资辅助决策系统 V1.0

- 项目代号：CN-WQDS
- 文档版本：V1.0 / 2026-11
- 状态：可运行 MVP（示例数据）
- 关联文档：`docs/architecture.md`、`docs/database.md`、`docs/acceptance.md`

---

## 1. 背景与目标

个人投资者在 A 股与场内 ETF 上做中期配置，普遍面临三个问题：

1. 信息与工具碎片化：行情、财报、公告、宏观数据分散，口径不一。
2. 决策靠感觉：缺少可复现的信号、仓位与失效条件。
3. 回测不可信：未来函数、无法成交、成本遗漏，导致“回测很美、实盘很惨”。

**产品目标**：为个人投资者提供一个**可解释、可回测、可审计、人工确认**的量化辅助决策工具，把“买什么、买多少、为什么、什么时候失效”写成结构化建议。

**非目标（V1.0 明确不做）**：

- 不接券商交易接口，不自动下单，不做资金划转；
- 不做高频、不做日内 T+0 回转、不做融资融券、不做期权/期货；
- 不做多用户 SaaS、不做跟单社区、不做收益承诺；
- 不做机器学习黑箱选股（V1.0 只用可解释因子与规则）。

---

## 2. 用户与场景

**目标用户**：有 50 万–500 万可投资产、能接受 10% 左右回撤、希望用规则替代情绪的个人投资者。

**核心场景**：

| 场景 | 频率 | 用户动作 | 系统输出 |
|---|---|---|---|
| 月度调仓 | 每月最后一个交易日 | 打开决策台，复核建议 | 决策卡 + 目标仓位 + 建议金额 |
| 风险预警 | 每日 | 查看风险状态 | GREEN/YELLOW/RED/HALT + 触发原因 |
| 策略研究 | 不定期 | 改参数、跑回测 | 样本内/样本外指标、PBO、压力测试 |
| 事后复盘 | 每季度 | 导出报告 | 净值、成交、被拒订单、审计日志 |

---

## 3. 产品边界与合规

- 系统输出为**辅助决策信息**，页面与报告必须常驻免责声明。
- 所有交易建议必须经用户手工确认；`automatic_execution: false` 为硬约束。
- 不展示“稳赚”“保本”“必胜”等表述；不承诺收益。
- 债券类资产优先通过**场内债券 ETF / 国债 ETF / 货币 ETF** 表达，不直接推荐个券；如未来接入个人债券，必须先做合格投资者准入核验。
- 数据与规则必须标注时点与版本；未核验的规则（如 2026-07-06 新规占位版）必须在界面与报告中标记 `verified=False`。

## 4. 功能需求

### FR-1 数据采集与质量

- FR-1.1 支持三种数据源：`sample`（合成，离线可复现）、`csv`（本地落地）、`akshare`（在线）。
- FR-1.2 所有行情、财报、宏观、公司行动必须带 `event_time`、`published_at`、`available_at`。
- FR-1.3 查询必须支持 `as_of(date)` 截断，严格 PIT。
- FR-1.4 质量检查至少 9 类：缺失字段、重复主键、价格非正、OHLC 逻辑、交易日缺口、异常收益、财报覆盖率、公司行动未复权、时间戳倒挂。
- FR-1.5 质量错误默认阻断决策（`reject_on_quality_error: true`），警告进入报告。

### FR-2 市场状态识别

- FR-2.1 用宽基指数（默认沪深 300）的 200 日均线、60/120 日实现波动、近 20 日成交量分位，划分 A/B/C/D 四种状态。
- FR-2.2 叠加宏观：CPI 同比、PMI、政策利率、10Y 国债收益率，输出状态解释。
- FR-2.3 状态只用于**解释与仓位约束**，不得作为收益预测卖点。
- FR-2.4 状态判定结果与输入指标写入 `market_regimes`。

### FR-3 因子体系

- FR-3.1 价值：EP、BP、SP、FCF Yield、股息率。
- FR-3.2 质量：ROE、ROA、利润增速、经营现金流/利润、资产负债率、盈利稳定性。
- FR-3.3 动量：21/63/126/252 日动量、相对强弱、12-1 动量。
- FR-3.4 风险：60/120 日波动、下行波动、最大回撤、Beta、流动性。
- FR-3.5 合成流程：MAD 缩尾 → 横截面 Z-Score → 行业中性 → 方向统一 → 加权 → 覆盖率门槛。
- FR-3.6 每个评分必须保留因子贡献度，供决策卡解释。

### FR-4 策略与组合

- FR-4.1 内置四个策略：双动量趋势、价值质量、低波核心、ETF 轮动；参数在 YAML，版本号 + 参数哈希可追溯。
- FR-4.2 组合优化支持等权、逆波动、风险平价、最小方差。
- FR-4.3 约束：单资产 ≤ 20%、单行业 ≤ 35%、总仓位 ≤ 98%、权重和 ≤ 100%。
- FR-4.4 约束投影必须把被截掉的额度回补到仍有空间的资产，避免“上限一剪→几乎全现金”的退化。
- FR-4.5 每个策略必须输出：目标权重、评分、理由、失效条件、持有期限。

### FR-5 回测

- FR-5.1 信号日收盘计算，下一交易日开盘成交（`next_open`）。
- FR-5.2 股票 T+1；债券/货币/黄金/跨境 ETF 按规则簿 T+0。
- FR-5.3 涨跌停不可成交、停牌不可成交、整手取整、现金不足拒单、参与率上限。
- FR-5.4 成本：佣金（最低 5 元）、印花税（仅股票卖出）、过户费、滑点、平方根冲击。
- FR-5.5 分红、拆股按公司行动调整持仓与成本。
- FR-5.6 输出净值、成交、被拒订单、目标历史、指标。
- FR-5.7 样本外：Walk-forward（504/126/126）与 CSCV PBO（10 分区）。

### FR-6 风控

- FR-6.1 风控政策独立于策略，YAML 管理，版本化。
- FR-6.2 风控可否决策略目标；策略不可覆盖。
- FR-6.3 检查项：数据完整性、单资产、行业、HHI、5% 以上持仓数、总仓位、杠杆、回撤、VaR/ES、波动突升、相关性、换手、单笔委托额、系统对账。
- FR-6.4 状态机 GREEN/YELLOW/RED/SYSTEM_HALT；RED 压降总敞口，HALT 拒绝生成调整。
- FR-6.5 审批令牌使用 HMAC-SHA256，绑定日期、策略、权重、状态；篡改或过期必须失败。
- FR-6.6 决策引擎缺审批必须抛错，不得静默降级。

### FR-7 决策输出

- FR-7.1 决策卡固定十字段：资产、信号、当前仓位、目标仓位、建议金额、风险等级、决策理由、失效条件、持有期限、数据时点。
- FR-7.2 信号枚举：买入/加仓/持有/减仓/卖出/观望。
- FR-7.3 输出 Markdown、JSON、CSV 三种格式。
- FR-7.4 报告必须包含：本期结论、风控意见、建议明细、压力测试、绩效指标、边界声明、生成时间。

### FR-8 监控与审计

- FR-8.1 每次运行写 `run_manifest`：配置摘要、策略快照、指标快照。
- FR-8.2 审计日志 JSONL 哈希链，支持 `verify()`。
- FR-8.3 记录数据质量、风控评估、决策批次、审批令牌。
- FR-8.4 失败必须显式报错并保留现场，不得静默跳过。

## 5. 非功能需求

| 编号 | 要求 |
|---|---|
| NFR-1 | 单机、单用户可运行；核心依赖仅 numpy/pandas/PyYAML |
| NFR-2 | 10 标的、5 年日频、月度调仓的回测在普通笔记本 ≤ 5 分钟 |
| NFR-3 | 全链路可复现：固定 seed、配置摘要、策略参数哈希 |
| NFR-4 | 关键路径有测试：PIT、规则、风控、成本、T+1、PBO、审计链 |
| NFR-5 | 输出 UTF-8；中文报告可直接阅读 |
| NFR-6 | 失败可诊断：异常写日志并保留中间产物 |
| NFR-7 | 不引入 scipy 等重依赖，降低个人部署门槛 |

## 6. 数据与口径

- 复权：价格面板同时保留 `adjusted` 与原始价；因子用复权价，成交与成本用原始价。
- 财报：`published_at = 期末 + 45 天`（示例），`available_at = published_at + 3h`；PIT 查询以 `available_at` 为准。
- 宏观：月度频率，`available_at` 为发布后次一交易日 09:30。
- 交易日历：2021–2026 内置节假日；周末与节假日不生成 K 线。
- 公司行动：现金分红、拆股；回测在除权日调整持仓数量与成本。

## 8. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 合成数据被误读为真实业绩 | 误导 | 报告与 README 显著标注“合成数据、非业绩展示” |
| 2026-07-06 新规理解错误 | 回测失真 | 规则簿 `verified=False` 占位，上线前人工核验 |
| 风控阈值过松/过紧 | 回撤或过度保守 | YAML 可调；压力测试 + 纸上交易校准 |
| 财报 PIT 时间不准 | 未来函数 | 强制 `available_at`，缺失即拒绝 |
| 个人债券准入 | 合规 | V1.0 只做债券 ETF，不推荐个券 |
| 界面被当成下单工具 | 操作风险 | 常驻免责声明；无交易接口；人工确认 |

## 9. 成功指标（产品验收）

- 一条命令可复现完整演示，审计链校验通过。
- 回测中至少能看到一次“涨跌停/停牌被拒单”和一次“风控裁剪”。
- 决策卡十字段完整，理由可追溯到因子或规则。
- 样本外与 PBO 可运行，结果进入报告。
- 新用户按 README 30 分钟内可跑通。

## 10. 后续版本方向

- V1.1：接入真实数据源、PostgreSQL 落库、增量更新与断点续跑。
